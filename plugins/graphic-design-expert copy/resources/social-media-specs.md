# Social Media Design Specifications (2025)

## Instagram
- **Portrait (Feed):** 1080 x 1350 px (4:5) *Recommended for max screen real estate*
- **Square:** 1080 x 1080 px (1:1)
- **Story / Reel:** 1080 x 1920 px (9:16)
- **Safe Zones:** Keep text centered 1080x1080 area for Reels to avoid UI obstruction.

## LinkedIn
- **Post (Portrait):** 1080 x 1350 px (4:5)
- **Post (Square):** 1200 x 1200 px (1:1)
- **Article Cover:** 1920 x 1080 px (16:9)
- **Carousel PDF:** 1080 x 1080 px or 1080 x 1350 px (Export as PDF, not JPG)

## YouTube
- **Thumbnail:** 1280 x 720 px (16:9)
- **Channel Banner:** 2560 x 1440 px (Safe area: 1546 x 423 px centered)

## Twitter / X
- **In-Stream Image:** 1600 x 900 px (16:9)
- **Header:** 1500 x 500 px

## Email (General)
- **Header Width:** 600px - 800px (Height variable)
- **Format:** JPG or GIF (max 1MB for load speed)
