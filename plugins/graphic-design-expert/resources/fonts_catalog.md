# Local Font Catalog

## Sans-Serif (Clean, Modern, UI)
- **System/Standard:** Helvetica Neue, Avenir Next, Verdana, Tahoma, Arial, Impact
- **Premium/Pro:**
  - **Graphik:** (Regular, Medium, Semibold, Bold) - *Excellent for modern UI*
  - **Proxima Nova:** (Regular, Medium, Semibold, Bold) - *Standard for tech startups*
  - **Montserrat:** (Thin to Black) - *Great for geometric headlines*
  - **Lato:** (Regular, Bold, Black)
  - **Gill Sans:** (Light to UltraBold) - *Humanist, friendly*
  - **Futura:** (Medium, Bold, Condensed) - *Geometric, architectural*

## Serif (Traditional, Editorial, Trust)
- **System/Standard:** Times New Roman, Georgia, Palatino, Baskerville
- **Premium/Pro:**
  - **Canela:** (Deck, Text, Display) - *High-fashion, editorial*
  - **Publico:** (Text, Headline) - *Newspaper/Editorial style*
  - **Minion Pro:** *Classic book typography*
  - **Didot / Bodoni:** *Luxury, high-contrast fashion*
  - **Charter:** *Highly readable for long-form text*

## Monospace (Code, Technical, Retro)
- **Developer:** Fira Code, 0xProto Nerd Font, Meslo, JetBrains Mono
- **Design:** PT Mono, American Typewriter, Andale Mono

## Display & Script (Creative, niche)
- **Script:** SignPainter, Snell Roundhand, Brush Script, Zapfino
- **Display:** Impact, Trattatello, Luminari, Chalkboard
