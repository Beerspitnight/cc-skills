# Production Specifications

## 1. Social Media (2026 Standards)
| Platform | Format | Dimensions | Aspect Ratio |
| :--- | :--- | :--- | :--- |
| **Instagram** | Portrait Feed | 1080 x 1350 px | 4:5 |
| **Instagram** | Story/Reel | 1080 x 1920 px | 9:16 |
| **LinkedIn** | Portrait | 1080 x 1350 px | 4:5 |
| **LinkedIn** | Cover | 1584 x 396 px | 4:1 |
| **YouTube** | Thumbnail | 1280 x 720 px | 16:9 |
| **Twitter/X** | In-Stream | 1600 x 900 px | 16:9 |

## 2. Print Production
- **Bleed:** 3mm standard (5mm for large format/packaging).
- **Safe Margin:** 5mm inside the trim line.
- **Resolution:** 300 DPI at final size.
- **Color Mode:** CMYK (Coated FOGRA39 or SWOP).
- **Rich Black:** C=60 M=40 Y=40 K=100 (Backgrounds).
- **Text Black:** C=0 M=0 Y=0 K=100 (Overprint).

## 3. Web & UI Hand-off
- **Touch Targets:** Minimum 44x44px (mobile).
- **Base Grid:** 8pt grid system.
- **Formats:**
  - Icons: SVG
  - Photos: WebP / JPG
  - Transparency: PNG / WebP
