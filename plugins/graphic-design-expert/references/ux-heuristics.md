# UX Heuristics & Usability Principles

## 1. Learnability
**Can a user figure it out the first time?**
- **Good:** Physical mapping (Controls match layout).
- **Bad:** Hidden gestures or unlabeled icons.

## 2. Efficiency
**Once learned, is it fast to use?**
- **Good:** "Enable FaceID" (Reduces login friction).
- **Bad:** 5-step checkout process for a guest user.

## 3. Memorability
**If I leave and come back, do I remember how it works?**
- **Good:** Standard patterns (Shopping cart in top right).

## 4. Error Forgiveness
**Does the design prevent errors or help you recover?**
- **Good:** "Undo" button in Gmail.
- **Bad:** Permanent deletion upon a single click.

## 5. Satisfaction
**Is the interaction pleasant?**
- **Good:** Micro-animations (Confetti on task completion).
- **Bad:** Loading spinners with no progress indication.
