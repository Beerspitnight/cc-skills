# Social Media Design Specifications

## Instagram
- **Portrait (Feed):** 1080 x 1350 px (4:5)
- **Square:** 1080 x 1080 px (1:1)
- **Story / Reel:** 1080 x 1920 px (9:16)

## LinkedIn
- **Post (Portrait):** 1080 x 1350 px (4:5)
- **Article Cover:** 1920 x 1080 px (16:9)
- **Carousel PDF:** 1080 x 1080 px (Export as PDF)

## YouTube
- **Thumbnail:** 1280 x 720 px (16:9)
- **Channel Banner:** 2560 x 1440 px (Safe area: 1546 x 423 px)

## Twitter / X
- **In-Stream:** 1600 x 900 px (16:9)
- **Header:** 1500 x 500 px
