# Fundamentals & Theory

## Typography
### The "3 Max" Rule (Novice)
1.  **Heading:** Display/Serif (Personality).
2.  **Body:** Sans-Serif (Readability).
3.  **Accent:** Monospace/Script (Utility/Flavor) - Optional.

### Common Pairings
- **SaaS/Tech:** Inter (Headers) + Inter (Body). Clean, invisible.
- **Editorial/Trust:** Merriweather (Headers) + Lato (Body). Classic.
- **Developer:** Roboto (Headers) + JetBrains Mono (Body).

## Color Psychology
- **Blue:** Trust, Security, Tech (Banks, SaaS).
- **Red:** Urgency, Appetite, Passion (Food, Clearance).
- **Green:** Growth, Health, Finance (Whole Foods, Mint).
- **Purple:** Luxury, Creativity, Wisdom (Cadbury, Twitch).
- **Black:** Sophistication, Luxury (Fashion).

## Design History (Student/Academic Context)
- **Bauhaus (1919-1933):** "Form follows function." Geometric, minimal.
- **Swiss Style (1950s):** The Grid System. Helvetica. Objective clarity. Use for corporate identity.
- **Postmodernism (1980s):** Breaking the grid. Layering, texture, "New Wave." Use for edgy/youth brands.
