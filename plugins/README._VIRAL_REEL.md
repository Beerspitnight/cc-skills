# Viral Reel Generator Skill

** A specialized Claude skill for engineering high-retention short-form video scripts (TikTok, Instagram Reels, YouTube Shorts).
Overview **

This skill transforms Claude into an expert short-form video strategist. Unlike standard writing prompts, this skill enforces strict "Anti-AI-Slop" rules to avoid generic cliches ("Let's dive in") and focuses on retention engineering—optimizing the first 3 seconds to stop the scroll.
Features

    ** Engineered Hooks:** Access to 5 proven viral patterns (Curiosity Gaps, Specificity Slams, Negative Urgency).

   ** Visual Scripting:** Outputs include visual cues ([Text Overlay], [Visual Action]) alongside audio.

    Two Distinct Styles:

        **Punchy:** Fast-paced, aggressive editing for trends/news (30-45s).

        **Deep Dive:** Educational, "how-it-works" breakdowns for technical topics (60s).

    **Mechanism-First:** Prioritizes explaining how things work rather than generic advice.

## Quick Start Template

To get the highest quality script immediately, copy and paste this block into your chat:
code Markdown

_I need a viral reel script. Here are the details:_

**Topic:** [e.g., Productivity / Coding / Fitness]
**The "Truth" (Mechanism):** [How does it actually work? e.g., "Caffeine blocks adenosine receptors"]
**The "Enemy" (Common misconception):** [What do people get wrong? e.g., "Drinking coffee immediately upon waking"]
**Style:** [Punchy or Deep Dive]

## Usage Guide
### 1. Generating a Script

You can be specific or vague. The skill is designed to ask "Discovery Questions" if you don't provide enough detail.

** Specific Request:**

    "Write a Punchy script about why 'To-Do Lists' fail, using the 'Negative Urgency' hook pattern."

** Vague Request:**

    "Write a reel about the new iPhone."
    (Claude will respond by asking for the specific Angle: Villain, Counter-Intuitive, or Deep Dive)

### 2. "Roast Mode"

You can feed existing scripts into the skill for optimization:

    "Roast this script I wrote. Fix the hook and remove any AI slop."
